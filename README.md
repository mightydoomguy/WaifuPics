WaifuPics
App for viewing and downloading anime arts


Libraries: 

- [Dagger Hilt](https://dagger.dev/hilt/) - DI
- [Retrofit](https://lysine.dev/retrofit/) - For API requests
- [Glide](https://bumptech.github.io/glide/) - For load pictures 
- [waifu.im](https://www.waifu.im/) - API
